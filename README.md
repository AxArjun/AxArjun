## Featured Work

**[FuelIQ](https://github.com/AxArjun/FuelIQ)** — Vehicle intelligence platform (production-grade build, in progress)
Flutter mobile app + FastAPI backend on PostgreSQL, Redis, and MinIO, with OCR receipt scanning and full architecture docs (PRD → system design → DB schema → 10M-user scaling plan). Containerized with Docker, CI/CD via GitHub Actions.

**[Worker Safety Detection System](https://github.com/AxArjun/Worker-safety-detection-System-v2)** — Real-time PPE compliance monitoring
YOLO-based computer vision pipeline with a FastAPI backend and Docker deployment, detecting safety violations from live video feeds for industrial environments.

**[Telco Customer Churn Analysis](https://github.com/AxArjun/telco-customer-churn-analysis)** — End-to-end churn prediction
SQL analytics, EDA, feature engineering, and a Random Forest classifier feeding a Power BI executive dashboard for customer retention strategy.

**[Enterprise Data Engineering Pipeline](https://github.com/AxArjun/Enterprise-Data-Engineering-Pipeline)** — Multi-database ETL architecture
End-to-end pipeline covering relational ETL, MongoDB document storage, and a star-schema data warehouse for analytical reporting.
